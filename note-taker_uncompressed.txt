# Therapy Session Analysis Pipeline

A Python-based project for analyzing therapy sessions from transcripts, YouTube videos, or audio recordings, and generating structured therapy notes. It also provides a dashboard interface for client/session management, analytics, administrative tasks (coding, billing), and clinical decision support.

## Features

- **Structured Note Generation:** Convert raw transcripts (text, YouTube captions, or audio) into standardized clinical notes (SOAP, DAP, BIRP, etc.).
- **LLM Integration:** Uses OpenAI or Google Gemini via LangChain and LangGraph to parse and structure therapist notes.
- **Dashboard UI:** A newly integrated dashboard (using the mockup from `mockup/DashboardLayout.jsx`) in `/dashboard` route for managing clients, sessions, analytics, and resources.
- **Database Integration (PostgreSQL):** A relational database schema for storing clients, sessions, transcripts, notes, diagnoses, billing entries, and recommended resources.
- **Caching &amp; Persistence:** Transcripts, notes, and extraction results cached in PostgreSQL for faster repeated requests.

## Prerequisites

- Python 3.9+
- Node.js 16+
- PostgreSQL (for database)
- OpenAI or Google API keys if using their LLMs.

## Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/yourusername/therapy-session-analysis.git
   cd therapy-session-analysis
   ```

2. **Install Python dependencies:**
   ```bash
   uv pip install -r requirements.txt
   ```

3. **Install Frontend dependencies:**
   ```bash
   cd frontend
   npm install
   cd ..
   ```

4. **Environment Variables:**
   - Copy `.env.example` to `.env` and fill in:
     ```bash
     cp .env.example .env
     ```
     Set:
     - `OPENAI_API_KEY` or `GOOGLE_API_KEY`
     - `DATABASE_URL` in the format: `postgresql://user:password@localhost:5432/theranote_db`
     - Other keys as needed.

   Example:
   ```bash
   export OPENAI_API_KEY="your-openai-key"
   export DATABASE_URL="postgresql://postgres:yourpassword@localhost:5432/theranote_db"
   export LANGCHAIN_API_KEY="your-langchain-key"
   export LANGCHAIN_TRACING_V2="true"
   ```

## Database Setup

1. **Create PostgreSQL Database:**
   Ensure PostgreSQL is running. Create a database:
   ```bash
   createdb theranote_db
   ```

2. **Apply the schema:**

3. **Insert mock data:**

@app.post("/generate", response_model=GenerateResponse)
async def generate_note(
    inputText: str = Form(...),
    formType: str = Form(...),
    inputType: str = Form("text"),
    audioFile: Optional[UploadFile] = File(None),
    forceRefresh: bool = Form(False)
):
    try:
        audio_file_path = None
        if inputType == "audio" and audioFile:
            # Save audio temporarily
            import tempfile
            with tempfile.NamedTemporaryFile(delete=False, suffix=".wav") as f:
                data = await audioFile.read()
                f.write(data)
                audio_file_path = f.name

        # Validate form type
        if formType not in FORM_SCHEMAS:
            return JSONResponse(
                content={"error": f"Unsupported form type: {formType}. Available types: {', '.join(FORM_SCHEMAS.keys())}"},
                status_code=400
            )

        # Process the input
        result = process_input(inputText, formType, inputType, audio_file_path, forceRefresh)
        
        # Check if result is a dictionary with error
        if isinstance(result, dict) and "error" in result:
            return JSONResponse(content=result, status_code=400)
            
        return {"note": result}
        
    except Exception as e:
        print(f"Error generating note: {str(e)}")  # Add logging
        return JSONResponse(
            content={"error": f"Failed to generate note: {str(e)}"},
            status_code=500
        )
    finally:
        # Cleanup temporary audio file if it exists
        if audio_file_path and os.path.exists(audio_file_path):
            try:
                os.unlink(audio_file_path)
            except:
                pass

@app.post("/notes")
async def create_note(note: Note):
    try:
        conn = get_db_connection()
        
        # Check for duplicate note
        if check_duplicate_note(conn, note.session_id, note.content, note.created_at):
            return JSONResponse(
                content={"error": "A note with these details already exists"},
                status_code=409
            )
        
        cur = conn.cursor()
        cur.execute("""
            INSERT INTO notes (session_id, note_text, created_at)
            VALUES (%s, %s, %s)
            RETURNING note_id
        """, (note.session_id, note.content, note.created_at))
        note_id = cur.fetchone()['note_id']
        conn.commit()
        cur.close()
        conn.close()
        return {"message": "Note created successfully", "note_id": note_id}
    except Exception as e:
        if isinstance(e, psycopg2.Error):
            # Handle specific database errors
            if e.pgcode == '23505':  # unique_violation
                return JSONResponse(
                    content={"error": "A note with these details already exists"},
                    status_code=409
                )
        return JSONResponse(
            content={"error": str(e)},
            status_code=500
        )

def process_input(
    input_text: str,
    form_type: str,
    input_type: str = "text",
    audio_file: str | None = None,
    force_refresh: bool = False,
) -&gt; str | dict:
    try:
        # Get transcript
        if input_type == "audio" and audio_file:
            transcript = transcribe_audio(audio_file)
        elif "youtube.com" in input_text or "youtu.be" in input_text:
            transcript = download_transcript(input_text)
        else:
            transcript = input_text

        if not transcript:
            return {"error": "No input text or transcript available"}

        llm = get_llm()
        schema = FORM_SCHEMAS.get(form_type)
        if not schema:
            return {"error": f"Unsupported form type {form_type}"}

        model_name = "unknown-model"
        try:
            from models.llm_provider import get_model_identifier
            model_name = get_model_identifier(llm)
        except Exception as e:
            print(f"Warning: Could not get model identifier: {str(e)}")

        if not force_refresh:
            cached = cache.get_extraction(transcript, form_type, model_name)
            if cached:
                return yaml.dump(cached, default_flow_style=False, sort_keys=False)

        structured_llm = llm.with_structured_output(schema=schema)
        response = structured_llm.invoke(transcript)

        if not response:
            return {"error": "Failed to generate note from the input"}

        result_dict = response.model_dump(exclude_unset=False, exclude_none=False)
        cache.store_extraction(transcript, form_type, result_dict, model_name)

        return yaml.dump(result_dict, default_flow_style=False, sort_keys=False)

    except Exception as e:
        print(f"Error in process_input: {str(e)}")  # Add logging
        return {"error": f"Failed to process input: {str(e)}"}

def process_entities(
    input_text: str,
    input_type: str = "text",
    audio_file: str | None = None,
) -&gt; str:
    try:
        if input_type == "audio" and audio_file:
            transcript = transcribe_audio(audio_file)
        elif "youtube.com" in input_text or "youtu.be" in input_text:
            transcript = download_transcript(input_text)
        else:
            transcript = input_text

        llm = get_llm()
        schema = EntitiesExtractionResult
        structured_llm = llm.with_structured_output(schema=schema, method="json_schema")
        response = structured_llm.invoke(transcript)

        result_dict = response.model_dump(exclude_unset=True, exclude_none=True)
        return yaml.dump(result_dict, default_flow_style=False, sort_keys=False)
    except Exception as e:
        return {"error": str(e)}

# Add new function to check for duplicates
def check_duplicate_client(conn, first_name: str, last_name: str, email: str | None) -&gt; bool:
    cur = conn.cursor()
    cur.execute("""
        SELECT COUNT(*) as count
        FROM clients
        WHERE first_name = %s AND last_name = %s
        OR (email IS NOT NULL AND email = %s)
    """, (first_name, last_name, email))
    result = cur.fetchone()
    cur.close()
    return result['count'] &gt; 0

def load_prompt(note_type: str) -&gt; tuple[str, str]:
    """Load the prompt template from YAML for the specified note type."""
    prompt_path = Path("langhub/prompts/therapy_extraction_prompt.yaml")
    with open(prompt_path, "r") as f:
        data = yaml.safe_load(f)

    note_prompts = data.get("prompts", {}).get(note_type.lower())
    if not note_prompts:
        raise ValueError(f"No prompt template found for note type: {note_type}")

    return note_prompts["system"], note_prompts["human"]


def create_extraction_chain(note_type: str = "soap") -&gt; RunnableSequence:
    """Create a chain for extracting structured notes."""
    print(f"Creating extraction chain for {note_type.upper()} notes...")

    print("Initializing LLM...")
    llm = get_llm()

    print("Setting up schema mapping...")
    # Select the appropriate schema based on note type
    schema_map = {
        "soap": SOAPNote,
        "dap": DAPNote,
        "birp": BIRPNote,
        "birp_raw": BIRPNote,
        "pirp": PIRPNote,
        "girp": GIRPNote,
        "sirp": SIRPNote,
        "fair_fdarp": FAIRFDARPNote,
        "dare": DARENote,
        "pie": PIENote,
        "soapier": SOAPIERNote,
        "soapie": SOAPIENote,
        "pomr": POMRNote,
        "narrative": NarrativeNote,
        "cbe": CBENote,
        "sbar": SBARNote,
    }
    schema = schema_map.get(note_type.lower())

    if not schema:
        raise ValueError(f"Unsupported note type: {note_type}")

    print("Creating structured LLM output...")
    # Create structured LLM
    structured_llm = llm.with_structured_output(schema=schema, include_raw=True)

    print("Loading system prompt...")
    # Load system prompt and human prompt for the specific note type
    system_prompt, human_prompt = load_prompt(note_type)

    print("Creating prompt template...")
    # Create prompt template
    prompt_template = ChatPromptTemplate.from_messages(
        [("system", system_prompt), ("human", human_prompt)]
    )

    print("Building extraction chain...")
    # Create the chain
    chain = prompt_template | structured_llm

    print("Extraction chain created successfully")
    return chain


def process_session(url: str, note_type: str = "soap") -&gt; dict:
    """Process a single therapy session."""
    try:
        # Download transcript
        print(f"Downloading transcript from {url}...")
        transcript = download_transcript(url)

        # Create extraction chain
        chain = create_extraction_chain(note_type)

        # Process transcript
        print("Extracting structured notes...")
        result = chain.invoke({"note_type": note_type.upper(), "text": transcript})

        return result.model_dump()

    except Exception as e:
        print(f"Error processing session: {str(e)}")
        return {}


def main():
    # Example YouTube sessions
    sessions = [
        {
            "title": "CBT Role-Play – Complete Session – Part 6",
            "url": "https://www.youtube.com/watch?v=KuHLL2AE-SE",
        },
        {
            "title": "CBT Role-Play – Complete Session – Part 7",
            "url": "https://www.youtube.com/watch?v=jS1KE3_Pqlc",
        },
    ]

    for session in sessions:
        print(f"\nProcessing session: {session['title']}")

        # Extract notes in different formats
        note_types = ["soap", "dap", "birp"]
        results = {}

        for note_type in note_types:
            print(f"\nExtracting {note_type.upper()} notes...")
            result = process_session(session["url"], note_type)
            results[note_type] = result

        # Print results
        print(f"\nResults for '{session['title']}':")
        for note_type, notes in results.items():
            print(f"\n{note_type.upper()} Notes:")
            print(yaml.dump(notes, default_flow_style=False))


if __name__ == "__main__":
    main()

import { NextRequest, NextResponse } from "next/server";
import { spawn } from "child_process";
import path from "path";
import { writeFile } from "fs/promises";
import { randomUUID } from "crypto";

// Force dynamic rendering and prevent caching
export const dynamic = 'force-dynamic';
export const revalidate = 0;

// Debug messages to filter out
const DEBUG_MESSAGES = [
  'Using provided text',
  'Generating',
  'Processing',
  'Converting',
  'Transcribing',
  'Audio file saved',
  'Starting transcription',
  'Completed transcription',
  'Extracting text',
  'Downloading transcript',
];

export async function POST(req: NextRequest) {
  try {
    // Add cache control headers
    const headers = {
      'Cache-Control': 'no-store, no-cache, must-revalidate, proxy-revalidate',
      'Pragma': 'no-cache',
      'Expires': '0',
    };

    // Handle FormData
    const formData = await req.formData();
    const inputType = formData.get('inputType') as string;
    const inputText = formData.get('inputText') as string;
    const formType = formData.get('formType') as string;
    const audioFile = formData.get('audioFile') as File;

    let audioFilePath: string | undefined;

    // If there's an audio file, save it temporarily
    if (audioFile &amp;&amp; inputType === 'audio') {
      const bytes = await audioFile.arrayBuffer();
      const buffer = Buffer.from(bytes);
      
      // Create a unique filename
      const fileName = `${randomUUID()}-${audioFile.name}`;
      audioFilePath = path.join(process.cwd(), '..', 'uploads', fileName);
      
      // Ensure uploads directory exists
      await spawn('mkdir', ['-p', path.join(process.cwd(), '..', 'uploads')]);
      
      // Write the file
      await writeFile(audioFilePath, buffer);
      console.log('Saved audio file to:', audioFilePath);
    }

    // Get the correct path to app.py (in the root directory)
    const appPath = path.join(process.cwd(), "..", "app.py");
    console.log("Python script path:", appPath);

    // Create Python process with correct path
    const pythonProcess = spawn("python", [
      appPath,
      "--input-text", inputText || '',
      "--form-type", formType,
      "--input-type", inputType,
      ...(audioFilePath ? ["--audio-file", audioFilePath] : []),
    ]);

    let result = "";
    let error = "";

    // Collect data from Python process
    pythonProcess.stdout.on("data", (data) =&gt; {
      const output = data.toString();
      console.log("Python output:", output);
      
      // Only add lines that don't look like debug messages
      const lines = output.split('\n');
      for (const line of lines) {
        const trimmedLine = line.trim();
        if (trimmedLine &amp;&amp; !DEBUG_MESSAGES.some(msg =&gt; line.includes(msg)) &amp;&amp; 
            !line.includes('audio file:') &amp;&amp; 
            !line.includes('.wav') &amp;&amp;
            !line.includes('.mp3')) {
          result += trimmedLine + '\n';
        }
      }
    });

    pythonProcess.stderr.on("data", (data) =&gt; {
      error += data.toString();
      console.error("Python error:", error);
    });

    // Wait for Python process to complete
    const exitCode = await new Promise((resolve) =&gt; {
      pythonProcess.on("close", resolve);
    });

    // Clean up the temporary audio file
    if (audioFilePath) {
      try {
        await spawn('rm', [audioFilePath]);
      } catch (error) {
        console.error('Error cleaning up audio file:', error);
      }
    }

    if (exitCode !== 0) {
      console.error("Python process failed:", error);
      return NextResponse.json(
        { error: "Failed to generate note: " + error },
        { status: 500, headers }
      );
    }

    try {
      // Try to parse the result as JSON
      const parsedResult = JSON.parse(result.trim());
      return NextResponse.json({ note: parsedResult }, { headers });
    } catch (e) {
      // If it's not JSON, return the raw result
      return NextResponse.json({ note: result.trim() }, { headers });
    }
  } catch (error: any) {
    console.error("Error in API route:", error);
    return NextResponse.json(
      { error: error.message || "Failed to process request" },
      { 
        status: 500,
        headers: {
          'Cache-Control': 'no-store, no-cache, must-revalidate, proxy-revalidate',
          'Pragma': 'no-cache',
          'Expires': '0',
        }
      }
    );
  }
}

import { spawn } from "child_process";
import path from "path";

export async function process_input(
  input_text: string,
  form_type: string,
  input_type: string = "text",
  audio_file?: File,
  force_refresh: boolean = false
): Promise&lt;string&gt; {
  return new Promise((resolve, reject) =&gt; {
    const pythonProcess = spawn("python", [
      path.join(process.cwd(), "main.py"),
      "--input-text",
      input_text,
      "--form-type",
      form_type,
      "--input-type",
      input_type,
      ...(audio_file ? ["--audio-file", audio_file.name] : []),
      ...(force_refresh ? ["--force-refresh"] : []),
    ]);

    let result = "";
    let error = "";

    pythonProcess.stdout.on("data", (data) =&gt; {
      result += data.toString();
    });

    pythonProcess.stderr.on("data", (data) =&gt; {
      error += data.toString();
    });

    pythonProcess.on("close", (code) =&gt; {
      if (code === 0) {
        resolve(result.trim());
      } else {
        reject(new Error(error || "Failed to generate note"));
      }
    });
  });
}

from __future__ import annotations
from pathlib import Path
import httpx
from deepgram import (
    DeepgramClient,
    DeepgramClientOptions,
    PrerecordedOptions,
    FileSource,
)
from config.settings import settings


class TranscriptionService:
    def __init__(self):
        if not settings.DEEPGRAM_API_KEY:
            raise ValueError("DEEPGRAM_API_KEY is not set in environment variables")

        # Initialize Deepgram client with options
        config = DeepgramClientOptions(
            verbose=False,  # Set to True for debugging
        )
        self.client = DeepgramClient(settings.DEEPGRAM_API_KEY, config)

    def transcribe_file(self, audio_path: str | Path) -&gt; str:
        """
        Transcribe an audio file using Deepgram.

        Args:
            audio_path: Path to the audio file

        Returns:
            Transcribed text with proper formatting
        """
        try:
            print(f"Transcribing audio file: {audio_path}")

            # Read file into buffer
            with open(audio_path, "rb") as file:
                buffer_data = file.read()

            # Create payload
            payload: FileSource = {
                "buffer": buffer_data,
            }

            # Configure transcription options
            options = PrerecordedOptions(
                model="nova-2",
                smart_format=True,
                language="en-US",
                utterances=True,
                punctuate=True,
                diarize=True,
            )

            # Transcribe with timeout
            response = self.client.listen.rest.v("1").transcribe_file(
                payload, options, timeout=httpx.Timeout(300.0, connect=10.0)
            )

            # Extract the transcript from the response
            transcript = response.results.channels[0].alternatives[0].transcript

            return transcript.strip()

        except Exception as e:
            raise Exception(f"Error transcribing with Deepgram: {str(e)}")

from youtube_transcript_api import YouTubeTranscriptApi
from urllib.parse import urlparse, parse_qs


def extract_youtube_video_id(url: str) -&gt; str:
    """Extract the video_id from a YouTube URL."""
    parsed = urlparse(url)
    if parsed.hostname in ("www.youtube.com", "youtube.com"):
        return parse_qs(parsed.query)["v"][0]
    elif parsed.hostname == "youtu.be":
        return parsed.path.lstrip("/")
    raise ValueError("Invalid YouTube URL")


def download_transcript(url: str) -&gt; str:
    """Download the YouTube transcript as a string."""
    video_id = extract_youtube_video_id(url)
    print(f"Downloading transcript for video ID: {video_id}")
    transcript_list = YouTubeTranscriptApi.get_transcript(video_id)
    full_text = " ".join([item["text"] for item in transcript_list])
    return full_text

from __future__ import annotations


def chunk_text(text: str, chunk_size: int = 3000) -&gt; list[str]:
    """
    Simple utility to chunk text into manageable pieces if needed
    for long transcripts.
    """
    words = text.split()
    chunks = []
    for i in range(0, len(words), chunk_size):
        chunks.append(" ".join(words[i : i + chunk_size]))
    return chunks

                # Already transcripts table exists, but we can also store raw cache if needed
                # For now, rely on main transcripts table.

    def _hash_content(self, content: str) -&gt; str:
        # Just a stable hash. Alternatively, could import hashlib.
        import hashlib
        return hashlib.sha256(content.encode("utf-8")).hexdigest()

    def get_extraction(self, input_content: str, form_type: str, model_name: str) -&gt; dict | None:
        input_hash = self._hash_content(input_content)
        with self.conn:
            with self.conn.cursor() as cur:
                cur.execute("""
                SELECT result FROM extraction_cache
                WHERE input_hash=%s AND form_type=%s AND model_name=%s
                """, (input_hash, form_type, model_name))
                row = cur.fetchone()
                if row:
                    return json.loads(row[0])
        return None

    def store_extraction(self, input_content: str, form_type: str, result: dict, model_name: str):
        input_hash = self._hash_content(input_content)
        with self.conn:
            with self.conn.cursor() as cur:
                cur.execute("""
                INSERT INTO extraction_cache (input_hash, form_type, result, model_name, timestamp)
                VALUES (%s, %s, %s, %s, %s)
                ON CONFLICT (input_hash, form_type, model_name) DO UPDATE SET
                result=excluded.result,
                timestamp=excluded.timestamp
                """, (input_hash, form_type, json.dumps(result), model_name, datetime.now()))

    def close(self):
        self.conn.close()

from __future__ import annotations
from config.settings import settings
from langchain_openai import ChatOpenAI
from langchain_google_genai import ChatGoogleGenerativeAI


def get_model_identifier(llm) -&gt; str:
    """Get a unique identifier for the model."""
    if isinstance(llm, ChatOpenAI):
        return f"openai-{llm.model_name}"
    elif isinstance(llm, ChatGoogleGenerativeAI):
        return f"gemini-{settings.GEMINI_MODEL_NAME}"
    else:
        return "unknown-model"


def get_llm(model_name: str | None = None):
    """
    Return an LLM instance based on the configured provider.
    """
    provider = settings.MODEL_PROVIDER

    if provider == "openai":
        model_name = model_name or settings.OPENAI_MODEL_NAME
        if not settings.OPENAI_API_KEY:
            raise ValueError("OPENAI_API_KEY is not set")
        llm = ChatOpenAI(
            model=model_name,
            openai_api_key=settings.OPENAI_API_KEY,
            temperature=0,
        )
    elif provider == "google_gemini":
        model_name = model_name or settings.GEMINI_MODEL_NAME
        if not settings.GOOGLE_API_KEY:
            raise ValueError("GOOGLE_API_KEY is not set")
        llm = ChatGoogleGenerativeAI(
            model=model_name,
            temperature=0,
            max_tokens=None,
            max_retries=2,
        )
    else:
        raise ValueError(f"Unknown model provider: {provider}")

    return llm

High-Level Overview

This project is a “Therapy Note Taker” system that processes therapy session inputs—textual transcripts, YouTube video transcripts, or audio recordings—and generates structured therapy notes in various standardized formats (e.g., SOAP, DAP, BIRP). The system uses large language models (LLMs), prompt templates, and structured output schemas to automatically extract clinical note components. It also includes a frontend (Next.js, Tailwind CSS) for user interaction and a backend (Python, LangChain, LangGraph) for data processing and note generation.

Main Concept
	1.	Input Sources:
	•	Text Input: Therapist can paste or type a raw session transcript.
	•	YouTube URL: The system can download and process the session transcript from a YouTube video (assuming the video has captions).
	•	Audio File: The system can transcribe an uploaded audio file (e.g., MP3) into text using a transcription service, then process the resulting transcript.
	2.	Note Formats:
The system supports various clinical note formats, each with its own schema and structure:
	•	SOAP (Subjective, Objective, Assessment, Plan)
	•	DAP (Data, Assessment, Plan)
	•	BIRP (Behavior, Intervention, Response, Plan)
	•	… and other formats like PIRP, GIRP, SIRP, FAIR/F-DARP, DARE, PIE, SOAPIER, SOAPIE, POMR, Narrative, CBE, SBAR.
	3.	LLM Integration:
The system uses LangChain and LangGraph to structure prompts and get outputs from LLMs (OpenAI GPT-4 or Google Gemini). It provides a prompt template for each note style, feeding the transcript to the LLM and expecting a JSON-like structured output that matches the chosen schema.
	4.	Frontend:
A Next.js-based frontend that:
	•	Lets users choose input type (Text, YouTube, Audio).
	•	Lets users choose note format.
	•	Provides a form to submit these inputs.
	•	Displays the generated note in real-time after the backend processes it.
	5.	Backend:
Python code handles:
	•	Transcription (from audio to text).
	•	Downloading transcripts from YouTube.
	•	Running the LLM with a chosen prompt template and schema.
	•	Returning structured results as YAML or JSON.
	6.	Caching &amp; Persistence:
A caching system stores transcripts and extracted notes to speed up subsequent requests.
	7.	Project Structure:
The code is divided into several directories and files for clarity:
	•	app.py, main.py: Entry points for processing.

	•	If input-type=audio, it transcribes the audio file.

- On the session details page, there’s an “Administrative” tab.
- Within the “Administrative” tab:
  - **Coding Automation Panel:** The system displays suggested CPT codes and rationale. The user can confirm or edit these codes.
  - **Billing Automation Panel:** Once codes are confirmed, the system auto-generates invoices. A “Generate Invoice” button triggers a modal showing invoice details (client name, service provided, fee). Therapist can finalize the invoice or adjust details before submission.

**UI Elements:**
- **Session Detail Page**: Tabs: “Overview”, “Notes”, “Administrative”, “Analytics”.
- **Coding Suggestion Card:** Shows recommended CPT codes, a short reason, and a dropdown for alternate codes if needed.
- **Invoice Preview Modal:** Itemized charges, payable amount, client details, and a “Submit to Insurance” or “Mark as Paid” button.

#### 2. Process Report Generation for External Sharing (Analytics &amp; Reporting)

**Location:** Under “Analytics &amp; Reporting” in the main navigation.

**User Flow:**
- Therapist goes to “Analytics &amp; Reporting” → “External Reports”.
- Select a client and a session range.
- A form to specify what level of detail to include (avoid clinical jargon, emphasize key progress points).
- Generate a downloadable PDF (with a “Download” button) or share a secure link.

**UI Elements:**
- **Report Configuration Panel:** Date range picker, toggle switches for including certain data (goals, improvements, homework compliance, etc.).
- **Preview Pane:** Shows a preview of the client-friendly summary.

#### 3. Client Progress Dashboard (Analytics &amp; Reporting)

**Location:** Also under “Analytics &amp; Reporting”.

**User Flow:**
- Therapist selects a client from a dropdown.
- The dashboard displays:
  - Mood trend line chart (scales of mood rating over time).
  - Session attendance history (bar or timeline chart).
  - Goals and progress indicators (progress bars or checkmarks).
- Interactive hover for data points: therapist hovers over a data point to see session notes.

**UI Elements:**
- **Charts and Graphs:** Line chart for mood over time, bar chart for attendance, a panel listing goals and their completion percentages.
- **Filters:** Date range filters, toggle for showing/hiding certain metrics.

#### 4. Sentiment and Emotion Analysis (Client Insight &amp; Feedback)

**Location:** Under “Client Insight &amp; Feedback”.

**User Flow:**
- Therapist opens a specific client’s session transcripts page.
- Select “Sentiment Analysis” tab to see:
  - Overall sentiment trend line over multiple sessions.
  - Word cloud or key emotion tags.
- Click on a particular session to see detailed sentiment analysis (e.g., percentages of sadness, anxiety, etc.).

**UI Elements:**
- **Emotion Summary Cards:** Cards showing dominant emotions each session (e.g., “Session 3: 70% anxious tone”).
- **Trend Charts:** A line or stacked area chart of sentiment categories over time.
- **Word Cloud:** Color-coded words frequently used by the client.

#### 5. Session Insights (Client Insight &amp; Feedback)

**Location:** Same general section as Sentiment Analysis.

**User Flow:**
- On a session’s detail page, select the “Session Insights” tab.

- Shows periods of silence or high activity as a timeline or waveform snippet.
- Therapist can toggle “Show Transcript Snippets” at silence points.

**UI Elements:**
- **Metrics Cards:** Talk time ratio, number of interruptions, silence durations.
- **Timeline Visualization:** A horizontal timeline with segments highlighted where client or therapist spoke, and silences marked.

#### 6. Personalized Resource Recommendations &amp; Insights/Suggestions (Client Support &amp; Resources)

**Location:** Under “Client Support &amp; Resources”.

**User Flow:**
- Therapist selects a client or session to see recommended resources.

**UI Elements:**
- **Resource Recommendation Card:** Title, short description, link, and relevance tag (e.g., “based on recent anxiety scores”).
- **Session Preparation Panel:** Pre-session checklist (embedded in upcoming appointment view), in-session guidance popup suggestions, and post-session assignment cards.

#### 7. Treatment Plan Suggestions, Suggest Diagnosis, Golden Thread Diagnosis (Clinical Decision Support)

**Location:** Under “Clinical Decision Support”.

**User Flow:**
- Therapist accesses a “Clinical Decision Support” page for a given client.

- **Golden Thread Diagnosis Tab:** A historical analysis summing up recurring themes, ensuring treatment is coherent over time.

**UI Elements:**
- **Diagnosis Suggestion Cards:** Each card includes code, description, confidence score. Accept or reject buttons.
- **Treatment Plan Editor:** A form pre-filled with suggested goals and interventions. Therapist can modify and save to the client record.

#### 8. Documentation &amp; Notes (Custom Templates, Note Generation, Speech-to-Text, Automated Summarization)

**Location:** Under “Documentation &amp; Notes”.

**User Flow:**

- **Custom Templates:** A “Manage Templates” page to create or edit templates.  
- **Speech-to-Text Transcription &amp; Summarization:** Upload audio, get the transcript and a summarized note suggestion. Present a side-by-side view: transcript on left, generated summary/note on right for quick comparison.

**UI Elements:**
- **Two-column layout:** Left column shows transcript or audio upload tool, right column shows generated note draft.
- **Template Selector:** A dropdown or modal listing available templates. Once selected, the note fields appear.
- **Summarization Card:** Key highlights and bullet points extracted from the transcript.

#### 9. Natural Language Search &amp; Query (Information Retrieval)

**Location:** A global search bar in the top navbar.

**UI Elements:**
- **Search Input in Navbar:** Large, easy to type in.

#### 10. Intelligent Appointment Scheduling (Scheduling &amp; Administration)

**UI Elements:**
- **Calendar View:** Monthly/Weekly view with available/unavailable blocks highlighted.
- **Suggestion Panel:** Recommended appointment times appear as a side panel with reasoning (e.g., “Client and therapist both free, no conflicts”).
